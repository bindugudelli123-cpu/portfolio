# Bindu Sri Gudelli — Portfolio

A responsive, static portfolio site with a warm editorial design, DM Sans + Playfair Display typography, project cards, skills, experience, credentials, and contact links.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

No build step is required. Google Fonts need an internet connection; system fallbacks are included.

## Deploy with GitHub Pages
1. Create a repository named `bindugudelli123-cpu.github.io` (or use an existing portfolio repository).
2. Upload the contents of this folder to the repository root.
3. In repository Settings → Pages, select deploy from the `main` branch and `/ (root)`.
4. Wait for the Pages build, then open the published URL shown in Settings → Pages.
